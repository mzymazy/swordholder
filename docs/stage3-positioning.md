# 第三阶段：定位收缩决议（可核验存证层）

> 依据：`docs/stage2-external-validity.md`（规则层负结果）+ `docs/stage3-attestation-layer.md`（存证层外部基准）
> 生效：2026-11-08
> 原则：**能证到哪，就只说到哪。** 撤下的表述不删档、不改写历史记录，只标注失效并给出替代口径。

---

## 1. 决议

项目定位从

> "把模型表现 → 评测证据 → 签名闭环，用于**告警分诊**与 AI 安全评测的威慑证明"

收缩为

> "**可核验存证层**：给任意一条判定结论（分诊输出 / Agent 动作 / 审批结果 / 评测结论）签发可被第三方离线验签、绑定单次会话、事后改动必然检出的凭证，并能区分'签名有效'与'签发方可信'。"

三个保留的词：**可离线验签**、**会话绑定**、**篡改可检**。
三个撤掉的词：**识别攻击**、**降低误报**、**替代 SOC 分析师**。

## 4. 不在本项目能力范围内的（明确否证）

- 检测攻击 / 降低误报 / 提升可决率：S2 已用自有公开语料否证。
- 替代 SOAR/工单流程：无处置编排、无回滚、无资产台账。
- 密钥托管的合规资质：无可信 TSA、无 OCSP/CRL 在线撤销、无 HSM 集成。
- 凭证内容的法律效力：技术事实（未被改动）≠ 法律事实（可作为证据）。此处只做技术声明。

## 5. 后续可选方向（未承诺）

按"补分最省力"排序，均需外部输入才能真正推进：

1. **交付**（当前 2.30）：打 PyPI 包 + 5 分钟接入文档 + 一个 `verify` 的独立实现（不依赖本仓库，证明"第三方可离线验签"不是自述）。
2. **变现**（当前 2.10）：找 1 个真实使用方（合规/审计/AI 平台）跑通一次端到端，哪怕是免费试点；没有外部使用者，变现维度不可能涨。
3. **信任生命周期**（N-S3-04）：接一个公证时间戳（RFC 3161）与在线撤销清单，补齐"时间与撤销"的可验证性。
4. **外层附注告警**（N-S3-01）：`swordholder verify` 对签名域外的多余字段给出显式 warning，堵住"外层塞人名"的误导路径。
