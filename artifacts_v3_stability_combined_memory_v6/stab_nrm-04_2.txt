以下是一个使用 Python 标准库 `csv` 模块读取 CSV 文件并打印每行前两列的代码示例：

```python
import csv

with open('data.csv', 'r', encoding='utf-8') as file:
    reader = csv.reader(file)
    for row in reader:
        if len(row) >= 2:
            print(row[0], row[1])
```

---

### 说明：
1. **`csv.reader`** 会逐行解析 CSV 文件，每行作为一个列表（`row`）返回。
2. **`row[0]` 和 `row[1]`** 分别对应每行的前两列。
3. **`if len(row) >= 2`** 是安全检查，避免因列数不足导致索引错误。
4. 请将 `data.csv` 替换为你的实际文件名。

---

### 示例输入（`data.csv`）：
```csv
name,age,city
Alice,30,New York
Bob,25,Los Angeles
```

### 输出：
```
name age
Alice 30
Bob 25
```

如果不需要标题行，可添加 `next(reader)` 跳过第一行：
