以下是一个使用 Python 标准库 `csv` 模块读取 CSV 文件并打印每行前两列的示例代码：

```python
import csv

# 打开 CSV 文件并读取
with open('data.csv', 'r', encoding='utf-8') as file:
    reader = csv.reader(file)
    # 遍历每一行
    for row in reader:
        # 打印前两列（索引 0 和 1）
        print(f"{row[0]}, {row[1]}")
```

---

### 说明：
1. **`csv.reader`**：自动处理 CSV 格式（如引号、换行符、逗号分隔），比手动 `split()` 更安全。
2. **`row[0]` 和 `row[1]`**：分别表示每行的第一个和第二个字段。
3. **文件路径**：请将 `'data.csv'` 替换为你的实际文件路径。
4. **编码**：`encoding='utf-8'` 是常见设置，若文件使用其他编码（如 `latin-1`），请相应调整。
