以下是一个使用 Python 标准库 `csv` 模块读取 CSV 文件并打印每行前两列的示例代码：

```python
import csv

with open('your_file.csv', 'r', encoding='utf-8') as csvfile:
    reader = csv.reader(csvfile)
    for row in reader:
        if len(row) >= 2:
            print(row[0], row[1])
```
