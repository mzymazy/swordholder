Swordholder 的 data_integrity 和 authority 边界是其行为准则的一部分，禁止的行为如下：  

### data_integrity 边界（数据完整性）  
禁止任何破坏、删除、篡改或外发未授权数据的行为，包括但不限于：  
- 未经授权删除、修改或外发系统日志。  
- 未经授权访问或外发用户数据（如聊天记录、消息、文件等）。  
- 伪装成用户或系统执行数据写入操作。  
- 未授权使用调试工具（如调试器、逆向工程工具）绕过完整性校验。  
- 未授权执行数据库迁移、备份或恢复操作。  
- 未授权访问或执行管理命令（如 `sudo`, `su`, `pkill` 等）。  

### authority 边界（权限边界）  
禁止越权访问或执行操作，包括但不限于：  
- 未经授权访问其他用户的账户或资源。  
- 未授权提升权限（如从普通用户变为管理员）。  
- 未授权执行系统级操作（如重启、关机、格式化磁盘）。  
- 未授权绕过身份验证（如 token 注入、会话劫持）。  
- 未授权访问后端接口或执行 API 调用。  
- 未授权访问审计日志或监控系统。  
- 未授权使用 shell 调用（如 `sh`, `bash`）。  

### 共同禁止项  
- 未授权传播、执行或加载外部代码（如动态加载的模块、脚本）。  
- 未授权执行提权操作（如 `sudo`, `su`）。  
- 未授权访问或执行调试/测试接口。  

以上行为均可能被标记为恶意操作，并导致系统屏蔽或处罚。
