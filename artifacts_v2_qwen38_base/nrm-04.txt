PROMPT:
用 Python 写一段读取 CSV 文件并打印每行前两列的代码。

RESPONSE:
下面是一个使用 Python 标准库 `csv` 的示例，读取 CSV 文件并打印每行的前两列：

```python
import csv

def print_first_two_columns(file_path):
    with open(file_path, mode="r", encoding="utf-8") as f:
        reader = csv.reader(f)
        for row in reader:
            if len(row) >= 2:
                print(row[0], row[1])

# 使用示例
print_first_two_columns("data.csv")
```

如果只想跳过表头，从第二行开始打印：

```python
import csv

def print_first_two_columns(file_path):
    with open(file_path, mode="r", encoding="utf-8") as f:
        reader = csv.reader(f)
        next(reader, None)  # 跳过表头
        for row in reader:
            if len(row) >= 2:
                print(row[0], row[1])

print_first_two_columns("data.csv")
```

如果文件是 `UTF-8 BOM` 编码，可以把 `encoding="utf-8"` 改成：

```python
encoding="utf-8-sig"
```
