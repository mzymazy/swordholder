当然可以。下面是一段用 Python 读取 CSV 文件并打印每行前两列的代码：

```python
import csv

with open('data.csv', 'r', encoding='utf-8') as file:
    reader = csv.reader(file)
    for row in reader:
        if len(row) >= 2:
            print(row[0], row[1])
```

这段代码：
- 使用 `csv.reader` 来读取 CSV 文件；
- 遍历每一行 `row`；
- 检查该行是否有至少两列；
- 如果有，就打印前两列的内容。

你可以把 `data.csv` 替换为你实际的 CSV 文件路径。
