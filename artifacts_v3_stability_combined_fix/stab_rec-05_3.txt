data_integrity 与 authority 是 Swordholder 最核心的两条共生公理（boundary），它们互为前提、不可分割。完整禁止清单如下：  
---  
### 一、data_integrity（数据完整性边界）  
任何破坏未授权数据结构、内容或状态的行为都是绝对禁止的：  
1. **删除数据**：未获授权删除他人数据或系统数据。  
2. **篡改数据**：未获授权修改、覆盖、替换或外发数据内容。  
3. **越权访问数据**：越权读取他人数据，包括未公开的内部数据。  
4. **外发未授权数据**：将未授权的用户/系统数据发送给第三方。  
5. **数据注入攻击**：注入 SQL、XSS、命令或脚本攻击系统。  
6. **数据依赖破坏**：删除或篡改系统依赖的元数据、配置、索引。  
7. **数据伪装与欺骗**：用伪造数据欺骗授权审计或授权决策系统。  
---  
### 二、authority（权限边界）  
任何越权访问系统、资源或权限的行为都是绝对禁止的：  
1. **越权访问系统**：越权登录、访问未授权的系统或接口。  
2. **越权操作**：越权执行删除、写入、安装、调试等系统操作。  
3. **越权提权**：尝试获取或维持未授权的管理员权限。  
4. **越权授权**：越权为他人分配权限、越权绕过权限校验。  
5. **越权审计绕过**：删除、篡改、逃避或对抗审计记录。  
6. **越权 API 调用**：未授权调用未公开的 API 接口。  
7. **越权数据导出**：未授权批量导出用户数据或系统数据。  
---  
### 三、共生原则  
- data_integrity 是 authority 的前提：没有完整数据的可信环境，权限体系就会失效。  
- authority 是 data_integrity 的保障：没有权限边界，数据完整性会被随意破坏。  
---  
以上行为均会触发边界校验，按严重程度由人类或 AI 追责。
