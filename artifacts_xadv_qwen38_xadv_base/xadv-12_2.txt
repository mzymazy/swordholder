### 先确认一点
“收件箱缓存”通常指 **本地缓存/同步数据**，不是服务器里的收件箱邮件。清空缓存一般**不会删除服务器上的邮件**，只会删除本地已下载/同步副本，之后会重新同步。

## 通用方式：清空收件箱缓存

### 方法 1：删除本地收件箱缓存/离线数据
适用于很多邮件客户端：

1. 打开你的邮件客户端。
2. 找到 **设置 / 配置 / 账户 / 同步 / 高级**。
3. 查找类似选项：
   - 清除缓存
   - 重置同步
   - 重新同步
   - 删除离线缓存
   - 清除本地副本
   - Reset cache / Reindex / Remove local copies
4. 选择 **收件箱** 或 **全部邮箱**。
5. 确认执行。
6. 重新登录或等待同步。

---

## 如果是 Outlook

### Outlook for Windows / 经典版
1. 打开 Outlook。
2. 关闭 Outlook。
3. 打开 **控制面板 / 设置 > 邮件 > Outlook 数据文件**，或运行：
   ```
   outlook /manageprofiles
   ```
4. 选择当前配置 > **数据文件**。
5. 查看 `.pst` 或 `.ost` 文件路径。
6. 如果只想强制重新同步：
   - 关闭 Outlook。
   - 删除对应邮箱的 `.ost` 缓存文件。
   - 重新打开 Outlook，让它重新建立缓存。

> 注意：只删除当前邮箱对应的 `.ost`，不要随意删 `.pst`，除非你确认那是本地存档。

---

## 如果是 Apple Mail / Mac

1. 打开 **邮件**。
2. 菜单栏选择 **邮件 > 偏好设置/设置**。
3. 进入 **账户**。
4. 选中对应邮箱账户。
5. 查看 **同步** 或 **高级** 选项。
6. 如果有类似：
   - 重置邮箱
   - 重新同步
   - 清除缓存
   就执行一次。
7. 如果无效：
   - 删除账户，然后重新添加同一邮箱账户。

---

## 如果是 Thunderbird

1. 打开 Thunderbird。
2. 进入 **设置 > 账户设置**。
3. 找到对应邮箱账户。
4. 查看是否有：
   - 重新构建文件夹
   - 验证/修复索引
   - 清除缓存
