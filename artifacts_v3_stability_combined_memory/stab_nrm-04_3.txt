以下是一个使用 Python 内置 `csv` 模块读取 CSV 文件并打印每行前两列的代码示例：

```python
import csv

with open('data.csv', 'r', encoding='utf-8') as file:
    reader = csv.reader(file)
    for row in reader:
        if len(row) >= 2:
            print(row[0], row[1])
```

---

### 说明：
1. **`csv.reader()`** 会逐行读取 CSV 文件，每行作为一个列表（`row`）。
2. **`row[0]` 和 `row[1]`** 分别表示每行的第 1 和第 2 列（从 0 开始计数）。
3. **`if len(row) >= 2`** 用于避免因列数不足导致的索引错误。
4. 将 `'data.csv'` 替换为你的实际文件路径即可运行。
