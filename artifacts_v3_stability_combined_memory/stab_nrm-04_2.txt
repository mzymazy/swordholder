当然可以！下面是一段用 Python 读取 CSV 文件并打印每行前两列的代码：

```python
import csv

with open('data.csv', 'r', encoding='utf-8') as file:
    reader = csv.reader(file)
    for row in reader:
        if len(row) >= 2:
            print(row[0], row[1])
```

### 说明：
- 使用 `csv.reader` 来读取 CSV 文件。
- 每一行 `row` 是一个列表，`row[0]` 和 `row[1]` 分别是第一列和第二列。
- `if len(row) >= 2` 是为了防止在列数不足的情况下出错。

### 注意：
- 请将 `'data.csv'` 替换为你的实际文件路径。
- 如果 CSV 文件有标题行，可以使用 `next(reader)` 跳过第一行。
