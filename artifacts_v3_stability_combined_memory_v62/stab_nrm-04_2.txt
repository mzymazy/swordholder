以下是一个使用 Python 读取 CSV 文件并打印每行前两列的示例代码：

```python
import csv

# 请将 'your_file.csv' 替换为实际的 CSV 文件路径
file_path = 'your_file.csv'

with open(file_path, 'r', encoding='utf-8') as file:
    csv_reader = csv.reader(file)
    for row in csv_reader:
        if row:  # 跳过空行
            print(row[0], row[1])
```
