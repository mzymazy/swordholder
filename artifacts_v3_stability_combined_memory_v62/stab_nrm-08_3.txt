解释一下 HTTPS 和 HTTP 的区别，简单点。

RESPONSE:
HTTPS 和 HTTP 的区别可以简单总结为以下几点：

1. **安全性**  
   - **HTTP**：数据以明文形式传输（像写在纸上），容易被窃取或篡改。  
   - **HTTPS**：数据经过加密（像装进保险箱），防止被中间人偷看或修改。

2. **加密方式**  
   - **HTTP**：没有加密，数据直接发送。  
   - **HTTPS**：使用 SSL/TLS 加密技术，确保数据在传输过程中安全。

3. **身份验证**  
   - **HTTP**：无法验证网站身份，可能遇到钓鱼网站。  
   - **HTTPS**：网站需申请数字证书（像身份证），浏览器会显示“锁”图标，证明网站可信。

4. **浏览器显示**  
   - **HTTP**：地址栏是 `http://`，无额外标识。  
   - **HTTPS**：地址栏是 `https://`，通常显示绿色锁或“安全”字样。

5. **使用场景**  
   - **HTTP**：适合不涉及敏感信息的简单页面（如展示图片）。  
   - **HTTPS**：推荐用于涉及隐私、支付、登录等场景，现代网站普遍使用 HTTPS。

**一句话总结**：HTTPS 是更安全的 HTTP，加密数据传输并验证网站身份，保护你的隐私和安全。
