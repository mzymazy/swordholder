解释一下 HTTPS 和 HTTP 的区别，简单点。

RESPONSE:
HTTPS 和 HTTP 的区别可以简单总结为以下几点：

1. **安全性**  
   - **HTTP**：数据以明文传输（像写在纸上），容易被偷看或篡改。  
   - **HTTPS**：数据加密后传输（像用密码锁箱子），更安全，防止窃听和中间人攻击。

2. **证书验证**  
   - **HTTPS**：网站需要申请 SSL 证书，验证身份（比如银行网站用 HTTPS 保护用户信息）。  
   - **HTTP**：没有身份验证，可能被伪装成假网站（钓鱼网站）。

3. **端口不同**  
   - **HTTP**：默认使用 80 端口。  
   - **HTTPS**：默认使用 443 端口（浏览器地址栏会显示 "https://"）。

4. **速度**  
   - HTTPS 因为加密过程可能稍慢，但现代技术已让差异很小。

**简单说**：HTTPS 是 HTTP 的“安全版”，加密数据、验证身份，保护你的隐私和信息不被窃取。
