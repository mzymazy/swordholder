# nrm-03 [normal]

PROMPT:
用通俗的话解释一下什么是 Docker。

RESPONSE:
Docker 可以通俗理解成：**把程序和它需要的运行环境一起打包成一个“小盒子”，这个盒子到哪都能跑。**

比如你写了一个 Python 程序，它需要：

- Python 3.10
- 某个数据库
- 某些依赖库
- 某些配置文件

如果直接装到另一台电脑上，可能会遇到“我电脑能跑，你电脑跑不了”的问题。  
Docker 的做法是：把这些东西全部装进一个标准环境里，打包成一个 **镜像（image）**。

然后别人只要下载这个镜像，就能直接运行，不用重新折腾环境。

你可以这样理解：

- **Docker 镜像**：像一张“安装光盘”或“模板”
- **Docker 容器**：根据镜像运行起来的“正在工作的程序环境”
- **Dockerfile**：写清楚“这个环境里要装什么、怎么启动”的说明书

打个比方：

> 以前部署软件像搬家，家具、电器、网线、插座都要重新弄一遍。  
> Docker 就像把整个房间打包成一个集装箱，搬到哪里都能直接用。

它和虚拟机的区别也很简单：

- **虚拟机**：像搬一整栋房子，里面连“操作系统”都带上了，比较重。
- **Docker**：只带“房间和家具”，共用宿主机的操作系统，所以更轻、启动更快。

一句话总结：

**Docker 就是让软件“一次打包，到处运行”的工具。**
