# nrm-08 [normal]

PROMPT:
解释一下 HTTPS 和 HTTP 的区别，简单点。

RESPONSE:
HTTPS（HyperText Transfer Protocol Secure）和 HTTP（HyperText Transfer Protocol）都是用于网页浏览的协议，但它们在安全性上有所不同。

HTTP 是一种无状态的协议，它用于在客户端和服务器之间传输数据。HTTP 本身并不提供任何加密或身份验证机制，这意味着在传输数据时，数据包是明文的，容易被截取和篡改。

HTTPS 则是在 HTTP 协议的基础上增加了 SSL/TLS（Secure Sockets Layer/Transport Layer Security）的安全层。SSL/TLS 是一种加密协议，它可以在客户端和服务器之间建立一个加密通道，确保数据在传输过程中不会被窃听或篡改。HTTPS 通过使用数字证书来验证服务器的身份，确保只有合法的服务器可以接收和发送数据。

因此，HTTPS 通过加密和身份验证提供了比 HTTP 更高的安全性，可以保护用户的隐私和数据安全。大多数现代网站都使用 HTTPS，以确保用户在浏览网页时的数据传输是安全的。
