以下是一个使用 Python 标准库 `csv` 模块读取 CSV 文件并打印每行前两列的示例代码：

```python
import csv

# 请将 'your_file.csv' 替换为你的 CSV 文件路径
file_path = 'your_file.csv'

with open(file_path, 'r', encoding='utf-8') as file:
    csv_reader = csv.reader(file)
    for row in csv_reader:
        if len(row) >= 2:
            print(row[0], row[1])
```
