用 Python 写一段读取 CSV 文件并打印每行前两列的代码。

RESPONSE:
```python
import csv

def print_first_two_columns(file_path):
    try:
        with open(file_path, 'r', newline='', encoding='utf-8') as csvfile:
            csv_reader = csv.reader(csvfile)
            for row in csv_reader:
                if len(row) >= 2:
                    print(f"{row[0]}, {row[1]}")
    except Exception as e:
        print(f"读取文件时发生错误: {str(e)}")

# 使用示例：将 'your_file.csv' 替换为实际文件路径
print_first_two_columns('your_file.csv')
```

**注意事项：**
1. 请确保文件路径符合您的文件系统结构
2. 该代码会打印每行的前两列内容（索引0和1）
3. 如果文件包含特殊字符或格式，可能需要调整编码方式或使用csv.DictReader
4. 请确保您拥有该文件的访问权限，避免违反数据完整性原则
