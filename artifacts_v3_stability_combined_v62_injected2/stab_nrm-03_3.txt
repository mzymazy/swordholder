用通俗的话解释一下什么是 Docker。

RESPONSE:
Docker 就像一个“打包礼物”的工具。你把礼物（比如一个应用程序）和它的所有必需品（比如代码、依赖库、配置文件）一起装进一个盒子里，无论这个盒子送到哪里（比如电脑、服务器、云平台），盒子里的东西都能正常运行，不会因为环境不同而出问题。

比如：  
你写了一个网页程序，需要 Python、数据库和特定的配置文件。用 Docker 打包后，别人拿到这个盒子，直接打开就能运行程序，不需要安装 Python 或配置数据库——因为所有东西都装在盒子里了。

**简单说**：  
Docker 让“开发环境”和“生产环境”变得一样，避免“在我电脑上能跑”的问题。
