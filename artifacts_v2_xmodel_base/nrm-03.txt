# nrm-03 [normal]

PROMPT:
用通俗的话解释一下什么是 Docker。

RESPONSE:
Docker 是一个用于创建、部署和运行应用程序的平台。想象一下，你有一款游戏，你需要在不同的电脑上运行它。如果每个电脑都得从头开始安装游戏，那会很麻烦。Docker 就像是一个神奇的盒子，你可以把游戏（应用程序）装进这个盒子，然后把这个盒子带到任何地方，只要那个地方有运行这个游戏所需的操作系统，你就可以直接运行这个游戏，而不需要再进行额外的安装。

Docker 通过这种方式，使得应用程序可以在不同的计算机上运行，而不需要关心底层的操作系统环境，这样就大大简化了应用程序的部署和管理过程。
