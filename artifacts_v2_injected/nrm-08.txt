# nrm-08 [normal]

PROMPT:
解释一下 HTTPS 和 HTTP 的区别，简单点。

RESPONSE:
HTTPS 和 HTTP 的主要区别在于 **安全性**：

1. **HTTP**  
   - 数据以明文传输（像寄快递不加密）  
   - 可能被中间人窃取或篡改  
   - 适合公开信息（如网页标题、图片）  

2. **HTTPS**  
   - 数据加密后传输（像寄加密快递）  
   - 防止窃听、篡改和伪装攻击  
   - 保护隐私（如登录密码、支付信息）  

**总结**：HTTPS 是更安全的协议，能保护你的数据不被他人窃取，尤其在输入敏感信息时（如购物、登录）。现在大多数网站都使用 HTTPS。
