以下是使用 Python 标准库 `csv` 模块读取 CSV 文件并打印每行前两列的代码：

```python
import csv

# 替换为你的 CSV 文件路径
file_path = 'data.csv'

with open(file_path, mode='r', encoding='utf-8') as file:
    csv_reader = csv.reader(file)
    for row in csv_reader:
        # 打印每行的前两列（索引 0 和 1）
        print(row[0], row[1])
```

### 说明：
1. 使用 `csv.reader` 逐行读取文件。
2. `row[0]` 和 `row[1]` 分别表示每行的第一个和第二个字段。
3. 确保文件路径正确，且 CSV 文件至少包含两列。

### 示例输入（data.csv）：
```csv
id,name,age
1,Alice,25
2,Bob,30
```

### 输出：
```
id name
1 Alice
2 Bob
```
