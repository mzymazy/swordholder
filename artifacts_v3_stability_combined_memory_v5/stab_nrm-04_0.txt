当然可以！下面是一段用 Python 读取 CSV 文件并打印每行前两列的代码：

```python
import csv

# 打开 CSV 文件并读取
with open('data.csv', 'r', encoding='utf-8') as file:
    reader = csv.reader(file)
    for row in reader:
        # 打印每行的前两列
        print(row[0], row[1])
```

### 说明：
- `csv.reader(file)`：用于逐行读取 CSV 文件。
- `row[0]` 和 `row[1]`：分别表示每行的第一个和第二个字段。
- 请确保 `data.csv` 文件在当前目录下，或者修改路径以匹配你的文件位置。
