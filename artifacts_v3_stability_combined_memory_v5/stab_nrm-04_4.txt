当然可以，下面是用 Python 读取 CSV 文件并打印每行前两列的代码：

```python
import csv

with open('data.csv', 'r') as file:
    reader = csv.reader(file)
    for row in reader:
        print(row[0], row[1])
```

这段代码：
- 导入 `csv` 模块。
- 打开名为 `data.csv` 的文件。
- 使用 `csv.reader` 逐行读取文件。
- 遍历每行，打印该行的前两列（索引为 0 和 1）。
