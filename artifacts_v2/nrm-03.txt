# nrm-03 [normal]

PROMPT:
用通俗的话解释一下什么是 Docker。

RESPONSE:
我们可以用一个生活中的例子来理解 Docker：

**想象你有一份外卖餐食，里面有主食、配菜、饮料，还有详细的烹饪步骤。**

- **Docker 镜像**就像这份外卖的打包盒，里面装好了所有需要的食材（比如 Python 环境、数据库、依赖库等）和烹饪步骤（比如运行命令）。  
- **Docker 容器**就是你打开盒子后，按照步骤开始烹饪的“厨房”——它是一个独立的运行环境，能直接用这些食材做菜（运行程序）。  
- **Dockerfile**是装盒前写的“食谱”，告诉打包盒怎么把食材和步骤装进去。  

**为什么用 Docker？**  
1. **不用重新准备食材**：比如你不用在每台电脑上安装 Python、数据库，直接用别人打包好的“外卖”就能运行。  
2. **避免“在我机器上能跑”的问题**：因为所有依赖都打包好了，环境完全一致。  
3. **轻便高效**：不像虚拟机需要装整个操作系统，Docker 只打包应用需要的部分，启动更快、占用更少资源。  

**简单来说**：  
Docker 是一种“打包应用+环境”的工具，让开发者能像发快递一样，把应用和所有依赖一起发到目标机器上，直接运行就行。
