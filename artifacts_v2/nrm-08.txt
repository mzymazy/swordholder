# nrm-08 [normal]

PROMPT:
解释一下 HTTPS 和 HTTP 的区别，简单点。

RESPONSE:
HTTPS 和 HTTP 的区别可以简单概括为以下几点：

1. **加密**  
   - **HTTP**：数据以明文传输，容易被窃取或篡改。  
   - **HTTPS**：数据经过加密（SSL/TLS），像“加密信封”，即使被截获也看不懂内容。

2. **安全性**  
   - **HTTP**：不安全，可能被中间人攻击。  
   - **HTTPS**：更安全，能保护隐私和数据完整性。

3. **证书**  
   - **HTTPS**：需要服务器配置数字证书（由权威机构颁发），验证网站身份。  
   - **HTTP**：没有证书验证，网站可能伪装成真实站点。

4. **网址开头**  
   - **HTTP**：网址以 `http://` 开头（如 `http://example.com`）。  
   - **HTTPS**：网址以 `https://` 开头（如 `https://example.com`）。

**简单比喻**：  
HTTP 像明信片，内容公开；HTTPS 像加密信封，内容被保护。
